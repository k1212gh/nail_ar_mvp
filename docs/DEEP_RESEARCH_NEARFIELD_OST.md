# 딥리서치 결과 — X3 근거리 격자 오버레이 (103 에이전트, 전 주장 3표 교차검증)

실행: 2026-07-03, `/deep-research`. 질문: `LIMITATIONS_FOR_DEEP_RESEARCH.md` 통합질문.
방식: 5각도 검색 → 소스 정독 → 주장별 3표 적대 검증(2/3 반박 시 기각). 기각 1건, 미검증 0건.

## 핵심 판정 (전부 3-0 만장일치 근거)

### 1. 단안(한쪽 눈) 주입의 "표준 경로"는 존재한다 — 단, X3에서 되는지는 온디바이스 프로브만이 답
- **OpenXR 코어 1.0**(확장 아님)의 `XrCompositionLayerQuad.eyeVisibility` = LEFT/RIGHT/BOTH.
  VIVE OpenXR Unity 플러그인이 실제 구현(Visibility 파라미터, 좌/우 별도 텍스처 또는 SBS+per-eye rect).
- **주의:** 컴포지션 레이어는 Unity가 아니라 **기기 런타임 컴포지터**가 그림 → center-eye 모노 복제
  정황인 X3 런타임이 이를 구현/존중하는지는 스펙만으론 단정 불가.
- **Unity 제약:** double-wide 스테레오(한 장에 좌|우) 경로는 현행 Unity에서 **완전 제거** —
  SBS 절반 그리기는 스테레오 API 밖에서 수동(screen-space 캔버스 x<640, viewport rect, 직접 blit).
- **동급 기기 실증:** XREAL One의 3D Mode = 프레임버퍼 절반↔눈 1:1 라우팅 실재(커뮤니티 실증 포함).
  additive OST는 검정=투명이라 **한쪽 절반에만 그리면 = 단안 표시**. 단 XREAL은 DP 테더 컨트롤러
  기능이라 X3 직접 이식 보장은 없음 → **ADB로 X3의 SBS/3D 모드 시스템 프로퍼티 탐색 가치**.

### 2. 물리 하한 재확인 (우리 기존 결론 강화)
- 시차 정합오차가 서브mm인 것은 **초점면 ±10cm 이내에서만** (사용자 스터디로도 검증, Cattari 2024).
- 오차 모델 ‖E‖≈O′·|p_z/d−1|: X3(4m)+손톱(25–40cm) → **오차 ≈ 0.90–0.94·O′** — 눈-렌더시점
  오프셋의 90%+가 그대로 정합오차. **개방루프 시스루 mm 정합은 소프트웨어로 불가능.**
- (기각 1건: "magnifier 하드웨어만이 유일 해법" 1-2 기각 — 단정 과도. 하한 자체는 견고.)

### 3. 아이트래킹 없는 캘리브 — 문헌 벤치마크
- **오프라인 카메라-대리(eye-replacement) 캘리브** (Pisa/VOSTARS): 오버레이 2.23px /
  5.98arcmin / **1.13mm** (650mm 검증면, 커스텀 단초점 HMD 조건 — 우리 조건에선 더 나쁨).
- **맨손 온라인 재캘리브** (Hu ISMAR 2021, rcICP): 손 윤곽을 가상 커서에 1회 정렬 → 수천 대응점 →
  3-DoF 병진만 갱신. 실사용자 0.4–0.6m: **7.71px ≡ 10.79arcmin** (스타일러스-SPAAM 9.57arcmin과
  근소 차, INDICA 14.49 대비 우위). → **X3 PoC 재캘리브 UX = "손을 격자 실루엣에 맞춰라" 1회 제스처.**

### 4. 카메라→디스플레이 거리의존 매핑 — 실행 레시피 (magic-mirror에선 유추 아닌 직접 적용)
2단 파이프라인:
1. **강체 베이스라인 AX=XB** (hand-eye): 체커보드 다시점 ~23세트, Tsai-Lenz + 비선형 최소자승.
   규칙: 근거리 타깃은 **병진** 오차가 지배(원거리는 회전) → 근거리 잔차는 X/Y 병진부터 조정.
2. **깊이별 호모그래피 LUT** (Salinas Sensors 2015): 작업공간을 깊이 평면으로 이산화, 평면별
   호모그래피(정규화 DLT+RANSAC, 점당 2px 초과 기각). 성능 RMSE 0.23px(평면)/0.84px(3D).
   → **우리용: 25/30/35/40cm 4평면 체커보드 캘리브, MediaPipe distM으로 선택/보간.**
   OST 시스루에선 per-user 정렬 제약이 붙지만 **magic-mirror(카메라→프레임버퍼)에선 그대로 적용.**

## 공백 (문헌에 없음 → 자체 실측으로 메울 것)
- **MediaPipe 단안 손거리 오차의 25–40cm 정량 + 개인 스팬 보정 개선폭**: 생존 클레임 0건 → 자로 실측.
- **지터/E2E지연/락온 시간의 손 스케일 벤치마크**: 없음 → Casiez/Azuma 기확보 근거로 자체 지표 설정.
