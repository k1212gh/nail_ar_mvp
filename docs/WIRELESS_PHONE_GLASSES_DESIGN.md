# 완전 무선(폰 + 안경, PC 없이) 설계

> 목표: **노트북/PC 없이 폰과 안경만으로** 손톱 검출 + AR 렌더 + (사장님 원격시청)까지.
> 2026-07-31 설계. 현재는 PC 의존(아래 3가지) → 각각을 폰/안경으로 옮긴다.

## 현재 PC가 하는 일 (=끊어야 할 의존)

| # | 역할 | 현재 | 무선화 대상 |
|---|---|---|---|
| 1 | **검출**(YOLO) | 안경→(USB adb reverse)→PC edge_serve(GPU) | **폰 온디바이스**(onnx) |
| 2 | **AR 렌더** | 안경 Unity 앱이 그림(검출데이터는 PC서 받음) | 안경 그대로, **검출데이터를 폰서 받게** |
| 3 | **원격시청**(사장님) | PC가 안경화면 screenrecord→릴레이 푸시 | **안경/폰이 직접 푸시** ← 가장 어려움 |

## 무선 아키텍처

```
        [안경 RayNeo X3]                         [폰 S22 Ultra]
  카메라 프레임 ──WiFi 소켓(8444)──▶  Nail Edge Server(onnx, 검출)
  AR 오버레이 렌더 ◀──JSON(nails)────────────┘
        │
        └─(원격시청용) 화면/합성 프레임 ──WiFi──▶ [오라클 릴레이] ◀── 사장님 브라우저
```

## 3가지 각각의 해법

### 1. 검출 → 폰 온디바이스 (설계 완료, 설치만 남음)
- 폰에 **Nail Edge Server 앱**(`android/`, onnx+소켓 8444) 설치. 실측 320²@0.08 = **134ms(7.5fps)**.
- 안경은 이미 소켓 접속 지원(`EdgeClient.cs`). **코드 변경 0.**
- **남은 것**: APK 빌드(`gradle -p android assembleDebug`, 모델 asset 복사) + `adb install` 1회.

### 2. AR 렌더 → 안경이 폰서 검출 받기
- 안경 설정을 `useSocket=1 sockHost=<폰IP> sockPort=8444`로. AR 렌더는 안경이 그대로 함.
- **설정 주입 문제(핵심)**: 지금은 `push_calib`가 **PC adb로** 안경에 설정을 씀 → PC 없으면 못 함.
  - **해법 A(권장, 쉬움)**: **한 번만 PC로** 안경에 "폰 IP로 접속" 설정을 넣어두면, 이후 안경이 그 설정을
    기억 → **PC 없이 재부팅해도 폰에 붙음.** ("최초 1회 PC 세팅 → 이후 무선"). 우리 백오피스 앱의
    설정 탭이 이 역할(폰 IP 입력·저장) — 단 적용은 에이전트(PC adb)가 하므로 **최초 세팅 때만 PC 필요.**
  - **해법 B(진짜 PC-free)**: 안경 앱에 **폰 IP 입력 UI**(또는 폰 화면 QR 스캔) 추가 → 안경만으로 설정.
    안경 앱 재빌드 필요.
  - **고정 IP 팁**: 폰 핫스팟이면 폰 IP가 고정(보통 192.168.x.1)이라 한 번 넣으면 안 바뀜 → 해법 A가 안정적.

### 3. 원격시청 → 안경/폰이 직접 릴레이에 푸시 (가장 큰 작업)
현재는 PC가 안경 screenrecord로 화면을 떠서 릴레이에 보냄. PC 없으면 누군가 대신 떠야 함.
- **해법 A(안경 앱)**: 안경 앱에 "합성 프레임을 릴레이로 POST"하는 경량 기능 추가(안경이 자기 AR 결과를
  주기적으로 JPEG로 릴레이 `/push`에 전송). 안경 앱 재빌드 필요. **가림도 안경 셰이더로 넣으면 이 푸시에
  그대로 반영**(§펜가림과 시너지).
- **해법 B(폰 앱)**: 폰이 검출과 함께 **합성뷰(카메라+디자인+가림)를 만들어** 릴레이에 푸시. 폰은 이미
  카메라 프레임을 받으니(검출용) 거기에 디자인+가림 합성(우리 `pen_occlusion.py`의 안드 포팅) 가능.
  → **이 경우 펜 가림이 원격시청에 자동 포함**(폰이 합성하므로). 단 안경 착용자 시야(OST)엔 별도.
- **해법 C(당장)**: 원격시청은 최초 세팅용 PC가 있을 때만. 무선 운영 중엔 로컬 AR만.

## 권장 로드맵 (난이도순)

1. **[쉬움] 최초1회 PC세팅 → 무선 운영**: 폰앱 설치 + PC로 안경을 폰에 붙이는 설정 1회 → 선 뽑고 폰+안경만.
   (원격시청은 세팅 PC 있을 때만.) — **여기까지가 "선 뽑아도 검출·AR 동작".**
2. **[중간] 폰 합성푸시**: 폰이 카메라+디자인+**펜가림** 합성뷰를 릴레이에 푸시 → **PC 없이 원격시청 + 가림.**
   `pen_occlusion.py`를 폰(Kotlin/onnx 파이프라인 옆)에 포팅.
3. **[큰작업] 안경 앱 자립**: 안경에 폰IP 설정 UI + 자기화면 릴레이 푸시 + 가림 셰이더 → 진짜 안경 단독.

## 필요한 것 (형 도움)
- 폰 **USB 디버깅 인증**(현재 폰 adb는 인증됨) → APK 설치 가능.
- **안경+폰 같은 WiFi**(또는 폰 핫스팟에 안경 연결) — 무선 검출의 전제.
- 안경 앱 재빌드가 필요한 단계(2 셰이더/3)는 **Unity·gradle 빌드 1회**.
