## 1. 펜 가림방지 (occlusion) — 완성

**목표**: 손톱 위에 펜/도구를 얹으면 디자인이 펜을 덮지 않게 (`design_alpha = nail AND NOT pen`).

**접근**: 도구 종류에 독립적인 **색-편차 기반**. 손톱 코어 Lab 중앙값 대비 편차 → 연결성분으로 "펜다운"
영역만 채택. 학습모델 불필요(온디바이스 가벼움).

**이번에 개선한 것**(이전 ~25% 오탐 바닥 → 대폭 감소):
- **하이라이트 제외**: 손톱보다 밝은(L↑) 스펙큘러 반사는 occluder 아님 → 가중치에서 제거.
  weight맵이 near-zero로 깨끗해짐(손톱 반사 오탐이 주범이었음).
- **연결성분 필터**: (면적 큼) AND (길쭉 OR 손톱경계 밖으로 뻗음)인 성분만 펜. 손톱 안 작은 무늬 탈락.
- **경계 링 제거**: 디자인 가림을 손톱 5px erode 안쪽에만 적용 → nail↔skin 전환 오탐 제거.

**검증**(안경 실측 187장: 사진 10 + 영상프레임 177):
- 검은 펜/금속 페룰 브러시가 손톱을 가로지르는 프레임(vf_076 등)에서 **디자인이 펜 위에서 자연스럽게
  흐려져 펜이 비쳐 보임**. 손톱 밖(손가락 주름) 잔여 오탐은 손톱 안에만 적용해 디자인 무영향.
- 한계(불변): 손톱과 색이 비슷한 도구(살색 연필)는 약함 → 실전 도구가 검은 펜/금속 브러시면 충분.

**산출물**:
- `web/pen_occlusion.py` — 재사용 모듈(`pen_soft_mask`/`apply_occlusion`). **라이브·테스트 단일 소스.**
- `tools/pen_probe/pen_mask_v2.py` — 이 모듈 import(코드 통일). 5패널 몽타주로 이미지 테스트.
- `web/edge_serve.py` — `NAIL_OCC_DEMO=1`이면 모니터에 실제 가림 데모(사장님 릴레이로 확인). 기본 off.
- 상세: `docs/PEN_OCCLUSION_PROGRESS.md` "완성(2026-07-31)" 절.
- **남음**: 온디바이스 셰이더(Unity B단계) — 이 soft 마스크로 `NailMeshRenderer` 디자인 알파를 곱하면
  안경 실렌더에도 적용(재빌드 1회 필요).

## 2. 검출 엔진 선택 (PC 에지 vs 폰 온디바이스) — 완성·배포

**왜**: 손톱검출(YOLO)을 어디서 돌릴지 매장 상황에 맞게 고르게. PC(GPU, 빠름/USB) vs 폰(노트북 없이
폰+안경만, 같은 WiFi, 온디바이스 7.5fps).

**앱 '설정(검출엔진)' 탭**(신규):
- PC/폰 엔진 카드 선택, 폰 IP/포트 입력, **연결 테스트**(저장 전에도 폼 값으로), **폰 설치 가이드**
  (APK 설치→앱 실행→IP 확인→테스트), 펜 가림방지 토글.

**배선**:
- 백엔드: `Setting` KV 모델 + `GET/PATCH /api/settings` + `POST /api/settings/test-edge`(폰 소켓 TCP connect).
- **중계 켜기** 시 서버가 현재 엔진/폰주소를 에이전트에 동봉 → 에이전트가 분기:
  - **PC**: `adb reverse` + `edge_serve.py`(GPU YOLO) + 컴포지터.
  - **폰**: `push_calib.py useSocket=1 sockHost sockPort=8444`로 안경을 폰 EdgeServer에 지정, PC edge 미실행.
- shared: `ShopSettings` zod + `client.settings` + `agent.command` 페이로드 확장.
- 폰 에지 실체: 네이티브 앱 "Nail Edge Server"(소켓 8444), `docs/PHONE_EDGE_SERVER_PLAN.md`. 실측 320²@0.08=134ms(7.5fps).

**검증**: 로컬 스모크(기본값→PATCH영속→test-edge 성공·실패 경로) + 배포 후 외부 `/api/settings` 라이브.

## 3. 디자인 카탈로그 이미지 업로드 — 완성·배포

- **디자인 추가**를 실제 사진으로: 파일 선택 → **canvas 자동 축소**(최대 360px, JPEG q0.82 ≈ 20~60KB)
  → data URL로 저장. 백엔드 의존성 0(기존 `thumbnailUrl` 활용), Fastify `bodyLimit` 4MB로 상향.
- 태그 입력, 미리보기, 카드 그리드에 썸네일 표시. **디자인 삭제**(🗑) 엔드포인트/버튼 추가.
- 검증: 배포 후 썸네일 data URL 라운드트립(생성→목록) 정상.
